# Промты генератора картинок

Шаблоны, по которым `scripts/gen-images.mjs` (issue #202) собирает промт для codex. Формат файлов и раскладка — в [entity-images.md](entity-images.md).

Генерация всегда в **два шага**:

1. **Описание.** codex получает только *имя сущности и пару фактов* (тип/размер для существа, школа и уровень для заклинания, тип и редкость для предмета) и формулирует одну фразу — визуальную идею **своими словами**. Текст SRD агенту не передаётся: описание должно быть нашим, а не производной лицензионного текста, и промт от этого не раздувается.
2. **Картинка.** Фраза из шага 1 вставляется в шаблон своего вида, скрипт отдаёт готовый промт агенту дословно. Агент только исполняет — он не рассуждает о сущности, иначе начинает «улучшать» промт.

Такое разделение даёт трассируемость: в summary прогона видно **что агент понял**, ещё до взгляда на картинку. Кривая картинка почти всегда — кривое описание на шаге 1, и чинится оно правкой инструкции, а не шаблона стиля.

## Общий скин

Один на все три вида (константа `STYLE_TAIL`): глубокий тёмный фон, фиолетовый rim-light `#7c3aed`, матовая «UI»-эстетика, композиция под круговой кроп, без текста, рамок и декора, 1024×1024 (ужимается в 512×512 webp).

Различается **натура**:

| вид | что рисуем | шаблон |
|---|---|---|
| `creatures` | бюст-силуэт: голова, плечи, верх груди; лица нет | `creatures` |
| `spells` | знак-иконка эффекта: одна доминирующая форма в пустоте, без заклинателя и сцены | `spells` |
| `domain-cards` | то же самое: карты доменов Daggerheart — его способности | `spells` |
| `magic-items` | силуэт одного предмета целиком, без рук, носителя и подставки | `magic-items` |
| `gear` | то же самое: обычное снаряжение — верёвка, рюкзак, меч, доспех | `magic-items` |

Шаблонов три, видов пять: карты доменов рисуются как заклинания, снаряжение — как предметы. Дублировать текст промта ради нового вида не нужно, достаточно указать `prompt` в описании вида.

## Шаблон «заклинание»

**Шаг 1** (`DESCRIBE.spells`) даёт агенту: имя, школу, уровень (или «cantrip»). Просит одну фразу — доминирующая форма (стихийная форма, руноподобный глиф, луч, вспышка, вихрь) и один цвет энергии: огонь → тёплый оранжевый, холод → бледно-циановый, некромантия → болезненно-зелёный; если очевидного нет — остаётся фиолетовым. Запрещены существа, заклинатель, руки, окружение, сцена. Требование «читается мгновенно в малом размере» — отсюда «одна форма, не композиция».

**Шаг 2** (`PROMPTS.spells`) оборачивает фразу в «минималистичная арканная иконка, парящая в пустоте», плюс общий скин.

Примеры заполнения (реальные, из пилота):

| сущность | описание с шага 1 |
|---|---|
| Acid Arrow (Evocation, 2) | *A sharp, corrosive arrow shape glowing acid green.* |
| Aid (Abjuration, 2) | *A bold shield-shaped rune glowing radiant gold.* |
| Alter Self (Transmutation, 2) | *A split mask-shaped glyph shifting between two profiles, glowing violet.* |

## Шаблон «магический предмет»

**Шаг 1** (`DESCRIBE.magic-items`) даёт агенту: имя, тип, редкость. Просит одну фразу — что это за объект (клинок, посох, кольцо, флакон, плащ, сапоги, рог) и его определяющая форма, плюс сигнатурный материал или энергия (золото, серебро, пламя, иней). Ровно один объект: ни рук, ни носителя, ни фона, ни подставки — кроме случаев, когда сам предмет парный (сапоги, перчатки). Запрещены гравировки, надписи и любая поверхностная деталь, которой в силуэте не видно.

**Шаг 2** (`PROMPTS['magic-items']`) оборачивает фразу в «тёмный силуэт одного предмета, целиком, по центру пустого пространства», плюс общий скин.

Примеры заполнения (реальные, из пилота):

| сущность | описание с шага 1 |
|---|---|
| Adamantine Armor (Доспех, uncommon) | *A broad-shouldered suit of dark silver plate armor with a sharply tapered waist.* |
| Amulet of Health (Чудесный предмет, rare) | *A round gold amulet with a broad heart-shaped silhouette.* |
| Ammunition of Slaying (Боеприпасы, very rare) | *A single silver-tipped arrow with a long, needle-sharp point and a narrow feathered tail.* |

## Известное ограничение

Предметы, различающиеся только правилами, а не видом, дают почти одинаковые картинки: «Ammunition, +1/+2/+3» и «Ammunition of Slaying» — обе серебряные стрелы. Шаг 1 видит только имя и тип, а по ним разницы нет. Лечится либо точечной перегенерацией с ручной подсказкой (`ONLY=slug`), либо тем, что мы это принимаем: в списке предметы всё равно подписаны.

## Как перегенерировать одну картинку

```bash
# Удалить файл не нужно: ONLY игнорирует «уже готов».
KIND=spells ONLY=fireball node scripts/gen-images.mjs

# Посмотреть, что агент понял, не тратя генерацию:
KIND=spells COUNT=10 DESC_ONLY=1 node scripts/gen-images.mjs

# Посмотреть итоговый промт целиком:
KIND=magic-items COUNT=1 DUMP_PROMPT=1 node scripts/gen-images.mjs
```

Локально нужны `codex` (залогиненный), `cwebp` и сгенерированные данные API — `node web/scripts/gen-entity-data.mjs`.
