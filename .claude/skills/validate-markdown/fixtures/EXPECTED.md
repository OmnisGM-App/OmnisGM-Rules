# Ожидаемые результаты fixtures

Что `validate_markdown.py` должен находить в каждом тестовом файле. Номера строк
и северити сверены с фактическим выводом скрипта. Северити `note` печатается в
отдельном блоке «Заметки» и **не влияет на exit-код**; гейтят только
`error`/`warning`.

## broken-table.md

| Строка | Severity | Ошибка |
|---|---|---|
| 8 | error | Таблица 1: строка имеет 2 колонки, заголовок — 3 (пропущен `\|`) |
| 9 | error | Таблица 1: строка имеет 4 колонки, заголовок — 3 (лишний `\|`) |
| 13 | error | Таблица 2: отсутствует разделительная строка `\|---\|` после заголовка |
| 22 | warning | Таблица 3: разорвана пустой строкой (продолжение предыдущей таблицы) |

**Таблица 4** — ошибок быть не должно.

## broken-formatting.md

| Строка | Severity | Ошибка |
|---|---|---|
| 5 | error | Незакрытый `**` (bold без закрывающего маркера) |
| 9 | error | Незакрытый `*` (italic без закрывающего маркера) |
| 13 | error | Незакрытый inline-код (нечётное число `` ` ``) |
| 17 | note | `[Главе 3]` без `(url)` — битая ссылка или тег правил (SRD легитимно содержит теги `[Action]`) |
| 23 | warning | Пробелы внутри bold-маркеров (`** text **`) |

**Корректная ссылка** и **bold-italic** блоки (`**_…_**`, `***…***`) — ошибок быть не должно.

## broken-headings.md

| Строка | Severity | Ошибка |
|---|---|---|
| 7 | note | Прыжок уровня: `####` после `##` (канон 5.1 намеренно прыгает в stat-блоках) |
| 11 | warning | Нет пробела после `#` |
| 16 | note | Дублирующийся заголовок подряд: `Дубликат` |
| 20 | warning | Нет пробела после `##` |
| 32 | note | Нет пустой строки перед заголовком |

**Корректные подзаголовки** `###` и `####` — ошибок быть не должно.

## broken-whitespace.md

| Строка | Severity | Ошибка |
|---|---|---|
| 5 | warning | Двойные пробелы в тексте |
| 20 | warning | 3+ пустых строк подряд |
| 25 | note | `--` вместо `—` (em dash) |
| 27 | note | ` - ` вместо ` — ` в предложении |

Примечание: проверки trailing whitespace и «строка из пробелов» в скрипте есть,
но в этой фикстуре таких байтов физически нет — редакторы срезают их при
сохранении. Не добавлять их сюда без бинарной фиксации файла.

**Корректный текст** и **список** — ошибок быть не должно.

## pair-en.md ↔ pair-ru.md (парная проверка)

| Проверка | Severity | Ошибка |
|---|---|---|
| Blockquotes | error | Строк blockquote: EN=3, RU=2 (потеряна строка "It can fly at great speeds") |
| Списки | error | Элементов списков: EN=3, RU=4 (лишний «Четвёртый элемент») |
| Строки | warning | Число строк расходится >5%: EN=25, RU=27 (лишний абзац в RU) |

**Заголовки и таблицы** — парная проверка должна пройти без ошибок (структура совпадает).
