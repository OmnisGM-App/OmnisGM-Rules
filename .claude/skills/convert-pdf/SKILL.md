# /convert-pdf — Конвертация PDF в markdown

## Использование

```
/convert-pdf <pdf_path> <game> <version>
```

Пример: `/convert-pdf /tmp/brp-srd.pdf brp srd-1.0`

## Алгоритм

### Основной способ — скрипт

Скрипт `.claude/skills/convert-pdf/convert_pdf.py` делает всё автоматически (venv на каждый конвертер, три конвертера, marker MPS→CPU fallback, таймауты, статистика). Читай его сводку `/tmp/{game}_{version}_convert_summary.json`.

```bash
python3 .claude/skills/convert-pdf/convert_pdf.py "{pdf_path}" "{game}_{version}"
```

Второй аргумент — префикс имён выходных файлов; передаём `{game}_{version}`, чтобы прогоны разных версий не перезаписывали друг друга.

Результат:
- `/tmp/{game}_{version}_marker.md`
- `/tmp/{game}_{version}_pymupdf.md`
- `/tmp/{game}_{version}_docling.md`
- `/tmp/{game}_{version}_convert_summary.json` — машиночитаемая сводка

### Ручной запуск

Скрипт сам создаёт venv (по одному на конвертер — PEP 668 + конфликт зависимостей marker↔docling) и ставит пакеты. Для кастомных параметров или одного конвертера вызывай нужный `/tmp/venv-<tool>/bin/...` напрямую (флаги: `marker_single --help`).

## Сильные и слабые стороны конвертеров

| Конвертер | Хорош для | Слаб в | Скорость |
|-----------|-----------|--------|----------|
| marker | Заголовки (уровни `#`), общая структура, таблицы | Может падать на MPS; на узких колонках кладёт каждое слово на свою строку (лечится `fix_word_per_line` в `/cleanup-artifacts`) | ~50 мин / 400 стр. |
| pymupdf4llm | Чистый текст абзацев, скорость | Таблицы (0 форматированных), разрывы строк | ~1 мин / 400 стр. |
| docling | Таблицы (структура `\|`), сложный layout | Заголовки (плоская иерархия), скорость | ~40 мин / 400 стр. |

## Обработка ошибок

Скрипт сам обрабатывает skip/stderr, требует минимум 2 из 3 успешных конвертеров и падает с кодом 1 иначе. При падении — смотри сводку и stderr, реши: доустановить недостающий конвертер или продолжить с тем, что есть.

## Технические требования

- Все результаты в `/tmp/` — коммитов нет
- Таймауты (в скрипте): marker 10 мин + 10 мин CPU fallback, pymupdf 5 мин, docling 60 мин
