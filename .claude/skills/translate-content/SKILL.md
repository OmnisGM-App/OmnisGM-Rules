# /translate-content — Перевод контента по глоссарию

## Использование

```
/translate-content <game> <version>
```

Пример: `/translate-content daggerheart srd-1.0`

## Алгоритм

### Шаг 1: Построение словаря терминов

Источник терминологии: словари `src/{game}/translate/` (авторитетный) + общий `src/translate/`.

1. Запусти скрипт (детерминированный парсинг таблиц и логов с лестницей приоритетов — логи побеждают словари автоматически):
   ```bash
   python3 .claude/skills/translate-content/build_term_map.py {game} {version}
   ```
   - При exit ≠ 0 (словари не найдены) — предложи сначала `/translate-glossary`
2. Прочитай готовый маппинг `{EN: RU}` из `/tmp/{game}_{version}_term_map.json` (ключ `terms`) — это словарь терминов для перевода. Конфликты (`conflicts`) и статистику по источникам (`sources`) скрипт печатает в сводке
3. **Reference-глоссарии других версий**: найди `src/{game}/*/ru/*_Glossary/00_Glossary.md`, исключив текущую `{version}` (пути также передаёт `/translate-srd` Phase 0.5). Если найдены — добавь их пары «Оригинал → термин» в маппинг с приоритетом ниже словарей `translate/` и логов
4. Статистику для вывода бери из сводки скрипта (`N терминов из M файлов, K переопределено логами, конфликты: C`)

### Шаг 2: Определение файлов для перевода

1. Найди все EN файлы: `src/{game}/{version}/en/**/*.md`
2. Исключи файлы глоссария (`*_Glossary/`)
3. Определи порядок перевода:
   - `00_Legal*` → первым (лицензия)
   - Затем по номерам (`01_`, `02_`, ...)
   - Подпапки: файлы внутри по номерам

```
Файлы для перевода: K файлов
- 00_Legal.md
- 01_Characters.md
- 02_Equipment.md
- 03_Classes/01_Barbarian.md
- 03_Classes/02_Bard.md
...
```

### Шаг 3: Перевод каждого файла

Для каждого файла (в определённом порядке):

1. **Прочитай EN файл** (большие — чанками с offset/limit, максимум 3000 строк)
2. **Переведи** с обязательным использованием словаря терминов:
   - Каждый EN термин из словаря → заменяется на RU эквивалент
   - Неизвестные термины → перевод по контексту, выведи предупреждение и **добавь в словарь** `src/{game}/translate/01_dictionary_base.md` (расширенные категории: названия разделов, подклассов, умений, рекуррентные фразы — см. `.claude/rules/translate-dictionaries.md`)
3. **Сохрани форматирование:**
   - Уровни заголовков (`#`, `##`, `###`, `####`) — количество и иерархия = EN
   - Bold/italic (`**text**`, `*text*`, `**_text_**`) — сохранить разметку
   - Blockquotes (`>`) — сохранить структуру (stat blocks)
   - Таблицы — количество строк и столбцов = EN
   - Списки — количество элементов = EN
   - Ссылки `[text](url)` — перевести text, url без изменений
   - **Пустые строки — строго 1:1 с EN.** Каждая пустая строка EN = пустая строка RU. Не добавлять и не убирать пустые строки. Количество строк RU файла ДОЛЖНО точно равняться количеству строк EN файла.
4. **Проверь структуру после перевода (ОБЯЗАТЕЛЬНО перед записью):**
   - **Количество строк: `wc -l` RU = EN (строго, допуск 0).** Это блокирующая проверка — если не совпадает, файл не записывается до исправления
   - Посчитай заголовки каждого уровня: RU = EN
   - Посчитай строки таблиц: RU = EN
   - Посчитай элементы списков: RU = EN
   - Если расхождение — исправь до записи файла
5. **Создай RU файл** в зеркальной структуре: `src/{game}/{version}/ru/{same_path}`
6. **Верификация** — запусти opus-агент через **Agent** (model: "opus"):
   - Агент читает `.claude/rules/translation-validation.md` и проверяет пару EN/RU файлов по ВСЕМУ чеклисту
   - Передай агенту: пути к EN и RU файлам, словарь терминов из глоссария
7. **Fix-цикл:**
   - Если агент нашёл ошибки → исправить → перезапустить верификацию
   - Если исправление меняет перевод термина → выполнить процедуру из `.claude/rules/terminology-propagation.md`
   - Повторять до 0 errors (warnings — принять или отклонить явно)
8. **Коммит** (только после чистой верификации): `Перевод {game} {version}: {filename}`

### Шаг 4: Итоговая проверка

1. Подсчитай файлы:
   - EN файлов (без глоссария): X
   - RU файлов (без глоссария): Y
   - X = Y — ОК
2. Запусти структурную проверку скриптом:
   ```bash
   bash .claude/skills/verify-content/compare_structure.sh src/{game}/{version}/en src/{game}/{version}/ru
   ```
3. Выведи итог:

```
Перевод завершён:
- Файлов переведено: K
- Предупреждения о неизвестных терминах: N (если есть)
- Структура: все проверки пройдены ✓
```

## Правила перевода

### Обязательные

- **Словарь — закон.** Каждый термин из глоссария переводится ТОЛЬКО по словарю
- **Структура = EN.** Количество заголовков, строк таблиц, элементов списков идентично
- **Форматирование неприкосновенно.** Bold, italic, blockquotes, ссылки — без потерь

### Стиль

Полные правила стиля: **`.claude/rules/translation-style.md`**.

Ключевое:
- Игромеханические термины с заглавной буквы (как в глоссарии)
- Числа без изменений
- Единицы измерения: feet → футов, pounds → фунтов (если не в глоссарии — по стандарту D&D/TTRPG)
- Имена собственные → транслитерация (если не в глоссарии)
- Перевод должен звучать как книга правил, а не как подстрочник
- Кальки, канцелярит, тяжеловесные конструкции — недопустимы
- Длинные предложения — делить, неестественный порядок слов — перестраивать

### Большие файлы (>3000 строк)

1. Читай чанками: offset=0 limit=3000, offset=3000 limit=3000, ...
2. Переводи чанками, сохраняя контекст между ними
3. Собирай полный RU файл перед записью
4. **После сборки — обязательная проверка `wc -l` RU = EN.** Если не совпадает — найти и исправить расхождение до коммита

### Параллельный перевод (оркестратор разбивает файл на части)

При разбиении большого файла на части для параллельного перевода:
1. Каждая часть переводит строго свой диапазон строк EN
2. **На стыках частей:** последняя строка части N и первая строка части N+1 не должны перекрываться или пропускаться
3. **После склейки частей:** обязательная проверка `wc -l` склеенного RU = EN. Расхождение недопустимо — найти стык с ошибкой и исправить

## Технические требования

- Все агенты используют **model: "opus"**
- Большие файлы — чанками через offset/limit
- Коммит после КАЖДОГО файла (не групповой)
- Зеркальная структура папок RU = EN
- Сообщения коммитов на русском
