# Правки контента и переводов — отдельным PR

Решение владельца 2026-10-02.

- Правка markdown-контента и переводов (`src/**`: тексты SRD, RU-переводы, словари `src/dnd/translate/**`) идёт отдельным PR. В PR с кодом (`.github/`, `web/`, `scripts/`, схемы, парсеры) её нет.
- Гейт в PR с кодом нашёл ошибку в контенте → правка уходит в свой контентный PR от `main`. PR с кодом ссылается на него в теле («зависит от #N») и после его мёржа перебазируется на `main`.
- Контентный PR несёт только контент: в теле — что поменялось построчно и чем подтверждено (строка словаря, запись API, страница PDF).
- Заголовок контентного PR — с префиксом `[Content]`.

Откуда: #368 (API классов) нёс две правки RU-таблиц заклинаний подклассов; вынесены в #369.
