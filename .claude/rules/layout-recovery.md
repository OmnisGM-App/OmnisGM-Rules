# Правила восстановления структуры документа (Layout Recovery)

Фаза B скилла `/cleanup-artifacts`. Восстановление структуры документа после PDF-извлечения.

**НЕ переписывать контент. Только восстанавливать структуру, разрушенную при конвертации.**

## 1. Разрывы строк внутри предложений

Правило: если строка обрывается и следующая начинается с маленькой буквы — склеить.

```
ПЛОХО:
To play, a group needs at least one set of these dice, though it is easier
and more convenient if each player has a
set.

ХОРОШО:
To play, a group needs at least one set of these dice, though it is easier and more convenient if each player has a set.
```

## 2. Дефисные переносы слов

Автоматизировано в `layout_recovery.py` (`fix_hyphen_breaks`); проверять глазами только пограничные случаи.

## 3. Разбитые составные слова

Правило: если слово разбито на две строки без дефиса и это явно искусственный разрыв — склеить.

```
ПЛОХО:          ХОРОШО:
four            four-sided
sided

role            roleplaying
playing
```

## 4. Номера страниц и колонтитулы

Удалять:
- Числа на отдельных строках между разделами (номера страниц)
- Повторяющийся текст на каждой «странице» (колонтитулы, headers/footers)
- Watermarks

## 5. OCR-маркеры и метаданные конвертеров

Удалять:
- `<PARSED TEXT FOR PAGE: X / Y>`
- `<!-- page X -->`
- Любые теги метаданных, добавленные конвертерами

## 6. Image placeholders

- `![](_page_2_Picture_16.jpeg)` — удалять декоративные (логотипы, орнаменты, разделители)
- Сохранять только осмысленные диаграммы и схемы

## 7. Таблицы

Пустые крайние столбцы (`|  |  |`) автоматизированы в `layout_recovery.py` (`fix_trailing_empty_columns`). Остальное — вручную:
- Отсутствующие `|` на краях строк — добавить
- Неравное количество столбцов в строках — выровнять
- Разделитель `|---|` отсутствует после заголовка — добавить
- Разорванные строки таблиц — склеить

## 8. Сломанные списки

Нормализовать смешанные стили:

```
ПЛОХО:
- 1. Definitions:
- (a) "Contributors" means

ХОРОШО:
1. Definitions:
   (a) "Contributors" means
```

## 9. Заголовки

Удаление **bold** из заголовков автоматизировано в `layout_recovery.py` (`fix_bold_headers`). Остальное — вручную:
- Заголовки без `#` — добавить правильный уровень
- Разные стили (`#### **1. INTRODUCTION**`, `### 1. INTRODUCTION`, `1. INTRODUCTION`) — нормализовать
- Сохранять иерархию уровней
- Убирать лишний uppercase из заголовков

## 10. Двухколоночная вёрстка

Восстановить правильный порядок чтения (конвертер мог перемешать колонки), используя:
- Нумерацию разделов
- Иерархию заголовков
- Связность абзацев
- Семантический поток текста

Если порядок неочевиден — вставить `<!-- possible layout ambiguity -->`.

## 11. Артефакты `<br>`

Автоматизировано в `layout_recovery.py` (`fix_br_artifacts`), но проверять глазами по контексту
(`<br>`, `<br/>`, `<br />` на местах, где вёрстка переносила строку):

Правило (по контексту):
- **Проза**: буква + `<br>` + строчная буква — разрыв внутри слова, склеить без пробела.
- **Проза**: во всех прочих случаях (перед заглавной, цифрой, знаком) — заменить на пробел.
- **Ячейки таблиц** (строка начинается с `|`): всегда заменить на пробел — это перенос
  многословного значения/шапки.

```
ПЛОХО:                        ХОРОШО:
the charac<br>ter's           the character's
On a failed Save<br>DC        On a failed Save DC
| Slot<br>Level |             | Slot Level |
| 7<br>Wis |                  | 7 Wis |
```

## 11a. Разрыв по словам (узкая колонка)

Автоматизировано в `layout_recovery.py` (`fix_word_per_line`).

На PDF с узкими колонками (стат-блоки SRD) marker кладёт **каждое слово на свою строку**
с одним ведущим пробелом. Формально markdown валиден и в браузере склеивается в абзац,
поэтому по виду результата дефект незаметен — но такой файл нельзя ни сверить построчно,
ни разрезать на разделы, ни прочитать в diff.

```
ПЛОХО:                        ХОРОШО:
*Large                        *Large aberration, lawful evil*
 aberration,
 lawful
 evil*
```

Скрипт включает склейку только если так разорван документ целиком (доля строк-продолжений
не ниже 30%) — на здоровом файле легитимные отступы вложенных списков и блоков кода не
трогаются. Строки-продолжения, начинающиеся с маркера списка, `|`, `#`, `>` или бэктика,
остаются на месте. **Исключение — арифметический хвост:** строка вида ` + 85)` или ` -`
целиком выглядит как продолжение формулы кубов и склеивается, а ` - 3 очка действия`
остаётся пунктом списка (после знака допускаются только цифры, кости `d` и закрывающая
скобка — размен намеренный: строка с буквами, кроме `d`, считается пунктом списка).

Приёмник склейки: к строке таблицы, подчёркиванию setext и фенсу продолжение не
приклеивается, содержимое блоков кода не трогается вовсе. **Заголовок — приёмник**, и это
главное, ради чего функция писалась: в разорванном выводе разорвано и имя раздела
(`### Adult` + `Red Dragon`), а запрет приёмника оставлял бы такие заголовки обрубками —
после чего документ не режется на файлы. Единственное исключение — продолжение,
начинающееся с `*` или `_`: это уже шапка статблока, к заголовку она не относится.

Перенос по дефису склеивается без пробела (`any non-` + `lawful` → `any non-lawful`),
иначе слово осталось бы битым, но уже внутри строки, где его не видно ни глазами, ни
`fix_hyphen_breaks`. Дефис засчитывается **только после буквы или цифры**: одинокий `-` —
это минус формулы (`14d10` + `-` + `28` → `14d10 - 28`) или маркер списка, там пробел нужен.

Непарный открывающий фенс — штатный артефакт такого вывода, поэтому при нечётном числе
фенсов в файле они не учитываются вовсе: иначе одинокий ``` увёл бы весь остаток файла в
«не трогать», и отказ был бы неотличим от «нечего чинить».

Мера: у SRD 5.1 (403 страницы) так разорвано 89% строк вывода marker.

## 12. Склеенные поля stat-блока

Двухколоночная вёрстка PDF склеивает несколько полей метаданных в одну строку.
Канон держит **одно поле на строку** (разделены пустой строкой). Автоматизировано в
`layout_recovery.py` (`fix_glued_fields`): строка, начинающаяся с `**Метка:**` и
содержащая 2+ меток `**...:**`, разбивается по полям.

```
ПЛОХО:
**Casting Time:** Action **Range:** 90 feet
**Components:** V, S **Duration:** Instantaneous

ХОРОШО:
**Casting Time:** Action

**Range:** 90 feet

**Components:** V, S

**Duration:** Instantaneous
```
